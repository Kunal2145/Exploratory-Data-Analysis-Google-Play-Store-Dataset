# 📱 Google Play Store App Analysis

## 📌 Project Overview

The Google Play Store contains millions of applications across different categories. This project performs **Exploratory Data Analysis (EDA)** on Google Play Store data to identify trends and understand factors related to app popularity.

The dataset contains **10,841 rows and 20 columns**, including information about app categories, ratings, reviews, installations, size, price, and other attributes.

## 🎯 Objectives

* Find the most popular app category.
* Identify the app with the highest number of installations.
* Find the largest-sized apps.
* Analyze app ratings and reviews.
* Find the number of apps with a **5.0 rating**.
* Identify the top 5 most installed apps in popular categories.
* Analyze Free vs Paid applications.
* Understand relationships between ratings, reviews, and installations.
